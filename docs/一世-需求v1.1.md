1. 产品定位

1.1 一句话定义【已定】

一款 2.5D 修仙世界仿真游戏：一切（世界、人物、衣物、组织、剧情、货币、恩怨、品阶、功法、法宝、修炼体系）由随机 + 任意组合 + 时间演化生成，而非预设内容。

1.2 核心差异【已定】

1. 不是产量问题：内容量由组合空间产生，不是靠堆资产。
2. 时间不可逆：世界从开天辟地洪荒年间起，只前进不回退。
3. 一世叠加：世界持续演化，玩家死亡不重置世界，后一世进入同一个仍在演化的世界。
4. 因果内生：恩怨、道德、秩序并非剧本，是交易与组织结构的产物。
5. 品阶贯穿且不可逆：人、动植物、资源、功法、法宝共享同一套品阶体系，升阶一生一次，降阶单向，重炼才重置。
6. 体系分立：人与动植物各有独立的修炼体系、境界、寿元表，不是同一套等级换皮。

1.3 明确不做【已定】

· 不做线性剧情驱动的主线叙事游戏。
· 不做“数值刷子”型循环。
· 不做万人同屏全服模拟 MMO（见第 8 章）。

2. 世界观

2.1 世界起点【已定】

· 时间起点：开天辟地 · 洪荒年间。
· 洪荒年间本身就有故事发生，不是“空跑几千年再让玩家入场”。
· 开局世界没有任何组织，只有散落的个体（见 2.6）。
· 每一世开局体验都在洪荒早期：无论玩家是第几世，进入时世界时间虽已推进，但玩家出身所在的节点处于该世界演化序列中的“洪荒早期形态”——低组织度、低灵气开发、资源原始。这是开局体验的统一锚点，不等于世界时钟重置。

2.2 时间轴性质与不可回溯条款【已定】

· 单向不可逆：世界史只追加，不回滚。
· 域内独立时钟：不同空间有自己的时间流速（见 4.1、2.16）。
· 跨域因果顺序：以“本地时钟 + 跨界进入序号”全序排序，禁止回到更早的进入序号。

不可回溯条款：

· 玩家不能读档回到过去：死者不复活、已发生的事不能撤销、死亡永久进入下一世。
· 不能靠 S/L 重刷投胎结果——评分的主观性因此更硬（见 6.2）。
· 存档必须是世代链（见 5.6）：每次死亡，该世代档案转只读封存，新一世在同一世界上继续追加。
· 唯一的“时间倒退”例外是崩溃恢复：手机杀后台/断电后按已记录事件重放，不改变任何已发生的事。此工程必须做，否则随时丢档。

2.3 空间结构（空间图）【已定】

```
节点：主世界(洪荒大陆) / 各洲 / 秘境 / 上古小世界 / 洞天福地 / 洞府 / 飞舟内部
边  ：传送阵、空间裂隙、飞升通道、秘境入口、阵纹匹配入口、小世界连接通道
```

· 瞬移 = 图上的一条边（跨节点）。
· 御剑飞行 / 飞舟 = 同一节点内的位移（不跨节点）。
· 飞行与瞬移是两套独立规则，互不干扰。

2.4 力量体系：人与动植物分立【已定】

人与动植物各有独立的修炼体系、境界划分、寿元表。 不是“同一套境界换皮给兽用”。

体系 修炼资源 境界结构 寿元表 典型特征
人族 灵气、功法、丹药、道统 独立境界链（名称待定） 独立寿元表（待定） 靠功法与道统，路径最宽
草木 灵气、水土、光、根系范围 独立境界链（化灵→树妖→…待定） 独立寿元表（远长于人，待定） 不能移动，影响半径成长
兽类 灵气、血肉、主人道统、血脉 独立境界链（妖犬→灵兽→…待定） 独立寿元表（因种而异，待定） 可依附主人，也可野化

具体境界名称、级数、每境寿元数值【待定】（第 12 章第 3 项）。已定的是结构：三套体系分立，各自有表，互不套用。

体系之间的交互：

· 跨体系可交易、可结仇、可依附（草木庇护小兽、兽依附主人、人采灵草）。
· 跨体系的战力比较不按境界名硬对齐，而按实际战力 + 品阶 + 环境综合判定（具体公式待定）。
· 品阶（凡/灵/神）横跨三套体系，是共同维度（见 2.15）；境界是各自体系内的纵向维度。

2.5 势力形态【已定】

没有“宗门系统”。宗门只是组织的一种形式，与部落、家族、国家、教派、帮派、商会并列为同一套“组织形式系统”的取值（见 2.6）。

2.6 组织形式系统【已定】

宗门只是组织的一种类型标签，不是体系起点。

2.7 社会第一驱动：资源交换【已定】

用户原话：“为什么有个人变成群体？因为资源的互换交易，双方得利。单一独立变成双人或多人合作形成群体，群体形成组织。”

模拟的原子事件是一次交换，不是“群体生成规则”。

三个前置条件（缺一不可）：

1. 禀赋差异：各人所拥有的资源不同。
2. 需求不平衡：各自缺的正好对方有。
3. 交换后双方净收益为正。

五级涌现链与判据：

```
① 个体：资源向量 + 需求向量 + 能力向量
        ↓ 出现净收益>0 的配对
② 交换：一次性交易（最弱连接）
        ↓ 重复交换 → 信任累积（关系边权重）
③ 关系：稳定的双边互惠
        ↓ 关系网络聚成簇
④ 群体：多人共占同一片资源 / 共御同一威胁（松散、无规则）
        ↓ 出现「公共资源 + 角色分工 + 惩罚机制」
⑤ 组织：有名字、有规则、有首领、能对外交易或开战
        ↓ 组织之间再交易 / 结盟 / 吞并
⑥ 天下秩序：联盟、朝贡、商道网络、势力版图
```

④→⑤ 的判据（组织成立三要件）：公共资源、角色分工、惩罚机制。具备三样，组织才能跨个体生死存续——这也是恩怨能跨代承继的载体。

2.8 货币与市场【已定：经济自发产生货币】

```
物物交换 → 需求双重巧合失灵 → 有人开始"先换成大家都愿意收的东西"
→ 接受度正反馈 → 收敛为一般等价物 → 货币
```

· 不预设开局发钱。
· 仿真唯一需要的关键数据：每个个体对每种商品的接受度。
· 洪荒早期一般等价物：兽牙、盐、干肉、兽皮、燧石，区域性货币各不相同。
· 灵气普及后：灵石会挤出其他货币，成为修士硬通货 → 自然结果，非强设。
· 双币体系：凡人日常与修士灵石，兑换率随灵脉丰枯浮动。

预留接口（本期不实现）：通胀紧缩、铸币权即权力、劣币与掺假、多币种汇兑。

2.9 家庭与代际投资【已定：家庭由利益建立】

底层视角：多一个人口就多一个劳动力、多一份战斗力、多一份保障；
顶端视角：繁衍、培养自己的亲信，巩固自己地位。

家庭 = 一种跨代投资契约型组织。
投入 = 抚养成本；产出 = 劳动回报 / 战力回报 / 养老 / 继承。
留存条件：投资回报率 ROI > 0。

· 人口曲线自动出现：太平多生、饥荒少生或弃养、战乱多生男丁、洪荒早期少生但结伴多。
· 开局第 1 tick：N 个散人；数十 tick 后，稳定合作的一对开始共同抚养 → 第一个家庭自发出现。
· 顶端视角导出：嫡庶之争、分家夺权、亲信变对手。

2.10 长寿社会（修仙特有）【推断，待确认】

寿元极长导致子孙从“资产”变为“竞争对手”：继承从“等”变“夺”；高修为子嗣可能反噬父辈；长辈可能为延寿吞噬子孙气运。修仙家族内斗烈度显著高于凡人家庭。草木与兽类的寿元表独立（见 2.4），其代际关系与人族不同。

2.11 组织野心与政治规模【已定：可长到帝国级】

组织野心不断膨胀，想越来越扩张、地位越来越高，追求更远更高的境界；帝国级与宗门都会在演化中不断发展与消灭。

· 组织携带野心值：行为倾向 ≈ f(首领人格野心, 组织实力, 环境压力/机会)。
· 实力涨 → 野心涨；首领更替 → 野心突变；被压制 → 野心暂时收缩。
· 政治规模上限由通信能力（控制半径）决定：

时代 通信能力 政治规模上限
洪荒早期 徒步 部落（几十人）
坐骑/飞舟 月级往返 城邦、区域联盟
传送阵普及 瞬时 帝国、朝贡体系
传送阵被毁 断开 帝国碎成诸侯

· 过度扩张导致崩解：控制半径超限 → 管理成本超过收益 → 分裂。

2.12 修仙组织生命周期【已定】

· 飞升即抽顶：最高战力离开 → 野心骤缩 → 常在数十年内衰败被吞。
· 道统分裂：教义分歧 → 分裂 → 支派数代后成死敌。
· 遗产继承：组织消亡后，功法库、领地、灵脉、债务、仇怨必须定义去向。

2.13 地图比例与小世界分层【已定】

地球当量锚点：地球陆地面积约 1.49 亿 km²。游戏内“1 个地球当量节点”= 陆地可活动面积约 1.49 亿 km²（海洋按低密度可通行/不可通行处理，不计入在册人口承载面积）。

层级 面积量级 在册上限 时钟域 例子
T0 洞府/飞舟 0.01~10 km² 0~50 可调 1~10× 寻常修士洞府
T1 村庄/小镇 1~100 km² 50~2,000 1× “只有村庄那么大的小世界”
T2 区域/洲 10⁴~10⁶ km² 2,000~50,000 1× 主世界的一个洲
T3 地球当量 ~1.49 亿 km² 10,000~100,000 1× / 10~100× “像地球那么大的小世界”
T4 宇宙型 不以面积度量 不进入 L0/L1 逐个体推进 分多个子节点挂载 “像宇宙那么大的小世界”

硬约束：T3 不是一张连续地形，而是由若干 T2 子节点通过连接通道组成的图；T4 是 T2/T3 子节点组成的子树。UE5 的 World Partition/Landscape 不得用于承载 T3 连续地形（移动端不可行，见 10.2.3）。

小世界连接通道：在空间图中为一条边，可有开启条件（境界门槛、阵纹匹配、消耗灵石、单向/双向），但不改变“世界只前进”。

“人在其中占多大面积”：不单独设“玩家占地面积”参数。玩家在 T3 上的存在感由可见范围（神识）+ 移动速度 + 因果影响半径共同决定。

2.14 一切皆资源与环境不可逆【已定】

原则：日月山川河流、一草一木皆是资源，可被人利用、开发、破坏、新增。

层级 资源粒度 记录方式
L0 玩家所在节点 具体物件（山头、灵脉节点、建筑、树木区块） 事件日志逐条追加：RESOURCE_DEPLETED / RESOURCE_CREATED
L1 牵连个体 所在节点的资源类别 聚合到“区域资源存量”
L2 区域统计 灵气浓度、植被覆盖、灵脉丰枯 统计量推进
L3 组织级 领地资源产出 年度统计

不可逆保证：L0/L1 的资源消耗写进 append-only 事件日志，重放时按顺序扣减，不存在任何“资源恢复”API。

“环境越好人气越足，破坏越狠灵气越差”：

```
区域人气吸引力 ≈ f(灵气浓度, 植被覆盖, 资源可采量, 安全度)
              − g(破坏累积, 荒芜标记)
```

修士“克制”不是道德系统——破坏灵脉会降低自己未来的修炼产出，是资源账本的直接后果。移山填海造成的破坏不可逆；种植、阵法养护、灵脉疏导为正向追加。

资源品阶：凡品资源人人可取；灵品资源需修为/工具门槛；神品资源极稀有，通常伴随争夺与因果。

2.15 品阶系统（凡品 / 灵品 / 神品）【已定】

适用范围（横向贯穿，不是人族专属）：

类别 品阶表现
人 凡人 / 普通修士 / 隐世大能，均带品阶标签（根骨、材质、潜力层级）
动植物 草木：凡草 / 灵草 / 神药；野兽：凡兽 / 灵兽 / 神兽
资源 凡品材料 / 灵品材料 / 神品材料（矿、木、水、火、气）
空间 凡地 / 灵地 / 神地（灵脉、洞天、秘境、小世界）
功法 凡品 / 灵品 / 神品（上限受创造者实力约束，见 3.11）
法宝/器物 凡品 / 灵品 / 神品（上限受炼制者实力约束，见 3.12）

三档定义：

品阶 定义 典型特征
凡品 无灵气亲和或极弱，遵循自然规律 不能修炼或修炼上限极低；普通草木、普通野兽、无灵根凡人
灵品 有灵气亲和，可修炼、可化灵、可被修士利用 灵草、灵兽、有灵根者、灵脉节点、灵器
神品 极稀有，自带异象/特殊规则，可影响周围环境 神药、神兽、天骄根骨、天地奇物、神器

品阶 ≠ 境界（必须区分）：

· 品阶 = 先天材质 / 根骨 / 潜力上限 / 灵气亲和层级。
· 境界 = 后天修为，且人与动植物各自有独立境界体系（见 2.4）。
· 二者独立但相关：凡品出身可修到高境界（逆袭），神品出身也可能陨落；品阶影响修炼速度、突破概率、寿元上限的倾向，不决定绝对命运。
· “隐世大能也分三六九等”指的是：大能之间有出身品阶/根骨品阶的差异，不是“大能境界再分三档”。

升阶规则【已定：一生只能升一次，且有条件】：

```
凡品 --升阶(有条件)--> 灵品 --升阶(有条件)--> 神品
```

· 每件物品/每个个体，一生只能经历一次升阶。凡品升到灵品后，不能再自行升到神品；灵品升到神品是另一条路径，但同样占用“唯一一次升阶”名额。
· 升阶有条件：机缘、资源投入、大能点化、长期浸润、渡劫等，具体条件按品类在参数表中定义（外置可扩，见 10.4）。
· 升阶不是必然：条件不满足则永远停在原品阶。

降阶规则【已定：升过后只能单向降】：

· 升阶之后，只能单向降阶，不能回升。灵品可因灵气枯竭、遭受重创、资源断供而降回凡品；但降回凡品后，不能再次升回灵品（那唯一一次升阶名额已经用掉）。
· 未升过阶的原生品阶，降阶规则按品类另定（待定，见第 12 章第 13 项）。

重置手段【已定：分解重炼】：

· 分解重炼是唯一的重置手段。把物品/器物分解为材料，重新炼制，品阶状态归零，重新获得一次升阶机会。
· 分解重炼的代价：原物品的附加属性、因果、记忆、道统关联可能丢失或改变（具体由重炼规则决定，待定）。
· 对个体（人、动植物）而言，“分解重炼”不适用——轮回投胎是另一套机制（见 6.3），投胎按因果账本重新采样品阶，不等于“重置升阶名额”。

品阶与投胎（接入 6.3 / 6.7）：

· 因果账本影响投胎品阶的采样权重：作恶多端 → 向凡品/非人凡品偏移；行善 → 向灵品/人偏移。
· “任何品阶都有机会”（呼应 6.3）：凡品不是绝路，只是起点更难；神品不是保险，怀璧其罪。
· 品阶采样仍走确定性重建（4.6 解法二），同种子必得同结果。

品阶与社会评价（接入 5.7）：

· 品阶影响初始印象权重（神品出身者天然受关注），但不决定最终评价。
· 神品者更容易被觊觎（杀人夺宝的优先级更高），这是 5.3 掠夺成本公式的自然结果。

品阶与资源经济（接入 2.8 / 2.14）：

· 凡品/灵品/神品资源的价格层级不同，但不预设价格表——价格仍由交易网络自发形成。
· 神品资源的发现会触发组织扩张、争夺、战争，这是 2.11 野心系统的直接输入。

外置可扩：品阶表（三档定义、各品类映射、升阶条件、降阶条件、重炼规则）属于 10.4 必须外置的参数表。

2.16 小世界开辟与时间流速自定义【已定】

用户表述：境界实力高的玩家能创造小世界，开辟空间节点。定义时间流速。空间大小与自定义时间流速必须有代价。

谁能开辟：达到一定境界（具体门槛【待定】，第 12 章第 16 项）的玩家/NPC，可创造小世界、开辟空间节点。低境界者只能开辟 T0 洞府（3.8），不能创造独立小世界。

能开辟什么：

可开辟物 对应节点层级 说明
洞府 T0 低境界即可，见 3.8
小世界 T1~T3（按预算） 需达到门槛境界
空间节点 T2~T3 小世界内的子节点，或主世界上的独立节点
连接通道 空间图的边 小世界之间的通道，可设开启条件

开辟面积预算：

```
可开辟面积预算 ≈ f(境界, 持续资源投入, 阵道/空间功法理解度)
             − 维护成本（超线性）
```

· 与 3.8 洞府“可持有数 ≈ f(境界, 神识, 持续产出)”复用同一预算器。
· 资源投入不足 → 开辟到一半退化、坍塌或暴露。
· 空间大小必须有代价：面积越大，维护成本超线性增长（灵气消耗、阵材、看守、定期加固），不是免费扩张。

时间流速自定义：

· 开辟者可为自己的小世界定义时间流速（相对主世界的倍率）。
· 流速必须有代价：
  · 倍率越高，维持成本（灵石/寿元/灵脉消耗）超线性增长。
  · 高倍率小世界的稳定性更差：更容易出现时间乱流、边界崩解、内部生灵寿元错乱。
  · 防“时间农场”：不允许“低成本高倍率”无限闭关，否则经济系统崩（与 4.1 一致）。
· 流速上限【待定】（第 12 章第 7 项）。

开辟的不可逆性：

· 小世界一旦开辟，其存在本身写入世界日志；但小世界可坍塌/消亡（维护不上、被攻破、开辟者死亡且无继承）。
· 坍塌后不可恢复（接入 2.2 不可逆），但其内部资源可能散落为遗迹，成为后续世代的机缘——这正是“上一世建的洞府，下一世可能挖到”（8.1）的机制落点。
· 小世界的品阶（凡地/灵地/神地）影响可支持的开辟面积上限与流速稳定性（接入 2.15）。

开辟的因果：

· 开辟小世界 = 从主世界“抽走”一片空间与灵气 → 对周边区域造成灵气稀薄（负向追加，接入 2.14）。
· 被抽走的区域可能引发原住民怨恨、组织争夺、因果债（接入 5.1）。
· 小世界内部生灵（若有）与开辟者的关系，按 5.1 交易语义处理——他们是“被创造者”，但不自动忠诚。

3.11 功法与特效生成【已定】

功法只能靠改良，不能随时改特效。

```
新功法 = 原功法 + 改良方向（威力 / 速度 / 消耗 / 异象形态）+ 改良成本
成本 = 对原功法的理解度 + 境界门槛 + 试错风险（有走火入魔概率）
```

功法品阶【已定：因人而异，受创造者实力上限约束】：

· 功法品阶（凡品/灵品/神品）在创造时确定，由创造者自身的境界 + 品阶 + 道统理解度共同决定上限。
· 同一门理念，宗师创造是神品，普通人创造是凡品。
· 创造者实力不足，无法创造出高于自身实力映射上限的功法；强行创造高品阶功法 → 走火入魔/反噬概率剧增。
· 改良不自动改变品阶：改良是同一品阶内的优化，不触发升阶。功法品阶若要提升，必须走 2.15 的升阶规则（一生一次，有条件）。
· 功法体系归属：人族功法、草木功法、兽类功法分属不同体系（2.4），跨体系修炼有额外门槛与风险。
· 盗法之仇：未授权改良他人功法 = 道统外流 → 创始人与门派记仇追杀。

特效由功法创始人创建时定义，可自定义：闪光、音效、形态——“霹雳斩”是火光/电光/水波皆可自定。

异象词库：金 / 木 / 水 / 火 / 土 · 风 / 雨 / 雷 / 电 · 花 / 雪 / 叶 · 日 / 月 / 星 ……（可扩展）。

```
功法 = {
  异象基底（五行 / 天象 / 草木 / 日月）
  形态（剑气轨迹 / 爆发环 / 缠绕 / 落雨 / 雷柱 / 花瓣乱舞…）
  材质（颜色、自发光、透明度、边缘软硬）
  音效（音色、混响、起手/命中/收招三段节奏）
  参数域（速度、范围、持续、冷却）
  品阶（凡 / 灵 / 神，上限受创造者实力约束）
  体系归属（人 / 草木 / 兽）
  创造者ID（用于谱系树与盗法追责）
}
```

必须遵守的三条约束：

1. 每次改良必有权衡（不可全项更优），否则 500 年后只剩唯一最优解。
2. 改良失败会反噬（走火入魔、经脉损伤、暴毙）。
3. 盗法之仇：未授权改良他人功法 = 道统外流 → 记仇追杀。

衍生效果：视觉谱系树（每个功法记 parent）——看剑气颜色与轨迹即可认出同源。

性能预算：2.5D 下特效走 Niagara + 材质叠加，手机同屏粒子数与特效条数硬上限，超出自动降级。

3.12 法宝与器物【已定】

法宝品阶【已定：因人而异，受炼制者实力上限约束】：

· 法宝品阶（凡品/灵品/神品）在炼制时确定，由炼制者的境界 + 品阶 + 炼器造诣 + 材料品阶共同决定上限。
· 同一种材料，宗师炼制是神品，学徒炼制是凡品。
· 炼制者实力不足，无法炼出高于自身实力映射上限的法宝；强行炼制高品阶法宝 → 炸炉/反噬/材料报废概率剧增。
· 材料品阶是硬门槛：凡品材料炼不出神品法宝，即使炼制者是大能。材料品阶与炼制者实力共同取低者作为上限。

法宝的升阶与降阶【已定：接入 2.15 通用规则】：

· 法宝一生只能升一次（凡→灵 或 灵→神），有条件。
· 升阶后只能单向降，降了不能升回。
· 分解重炼是唯一重置手段：把法宝分解为材料，重新炼制，品阶状态归零，重新获得一次升阶机会。代价是原法宝的附加属性、因果、器灵记忆可能丢失或改变。

法宝的品阶与功能：

品阶 典型特征
凡品 无器灵，仅材质加成，可被凡人使用
灵品 有微弱器灵/灵性，可认主，有主动法术，需灵力驱动
神品 有完整器灵/自我意识，自带异象，可成长，择主，有因果牵连

法宝与因果（接入 5.1 / 5.3）：

· 神品法宝自带因果：前任主人的仇家、未了之愿、器灵的执念会一并过户（同 3.8 洞府“抢来的洞府带前任因果”）。
· 杀人夺宝的优先级：法宝品阶越高，目标越显眼（接入 5.7）。
· 器灵可记仇、可认主、可背叛——具体规则待定（第 12 章）。

法宝与视觉（接入 9.0）：

· 凡品法宝无光效；灵品有材质自发光/微弱光晕；神品有异象（悬浮符文、环境光、器灵虚影）。
· 这是验收第 28 条“角色辨识度”的延伸——看法宝的光效与异象，能判断其品阶。

外置可扩：法宝品阶表、炼制配方、升阶条件、器灵规则属于 10.4 必须外置的参数表。

4. 时间与演化

4.1 时间流速（时钟域）【已定】

域类型 典型倍率 游戏意义
主世界（洪荒大陆） 1× 基准
洞天福地 / 上等秘境 10~100× 闭关修炼
上古小世界（洪荒遗存） 100~1000× 进去数月，外面已千年
玩家开辟的小世界 自定义，有代价（见 2.16） 自建流速，消耗灵石/寿元维持
时间乱流 / 绝地 0.1× 或凝滞 危险区域

· 天然产生故事：进秘境修炼十年，出关发现宗门已灭、旧友坐化——不需要专门写剧情。
· 防“时间农场”：流速倍率越高，维持成本越高，且稳定性越差（2.16）。

4.2 离线演化【已定】

关掉游戏，世界按 delta 继续推进；回来时按事件日志重放补算。

4.3 补算分级【推断，待确认】

· 域级：人口、灵气、势力按“年”批量推进，只记统计量。
· 个体级：只详细模拟玩家 + 有因果牵连的 NPC，其余采样统计。
· 不分级则“闭关百年”一次重算几十年，手机必卡死。

4.4 状态叠加与摘要压缩【已定】

· 存档 = 种子 + 事件日志（append-only），读档即重放。
· 历史摘要层：超过 N 年的事件压缩为“纪元大事记”，只保留影响当下的因果边。
· 熵控制：NPC 记忆、恩怨边必须衰减 + 摘要。

4.5 治乱循环【已定：自然涌现】

```
太平 → 人口增长 → 资源紧张 → 内部分配冲突 → 内乱或外战
→ 人口锐减、传送阵废弃 → 权力真空 → 荒野扩张 → 新强者整合 → 新帝国
```

· 周期约二三百年（与凡人世代吻合）。
· 玩家转世三次即可亲历一次完整循环。

4.6 规模与算力预算（10 万档）【已定】

定义：世界同时存活的在册个体上限 10 万（含修士与凡人），世界尺度为“国-界级”。

两条硬推导：

1. 10 万 × 每日 tick × 500 年 ≈ 1.8×10¹⁰ 次推进——逐个体全量模拟手机上不可能。
2. 500 年间累计死者约 90 万，若各存 1KB 即 90MB——不可接受。

解法一：四层推进

层 范围 数量 推进粒度 单帧预算
L0 详细 玩家所在节点内 200~800 秒 / 分 ≤ 8ms
L1 牵连 与玩家/组织有恩怨边的个体 ≤ 5000 日 ≤ 20ms
L2 区域统计 节点 / 省 / 洲 ~200 月 / 年 ≤ 10ms
L3 组织级 组织决策 ~500 年 ≤ 5ms
L4 墓碑 历史死者 ~90 万 离线批量压缩 一次性

解法二：个体可重建

```
个体 = 生成函数(世界种子, 个体ID, 世代, 归属组织, 品阶, 体系)
     + 差异记录（恩怨边 / 关键事件 / 属性偏离 / 升阶记录）
```

· 不存全量属性；个体离开玩家视野即降级为统计项，重新进入视野时按公式确定性重建。
· 墓碑压缩：无恩怨边、无组织影响的凡人死者只进区域统计后丢弃；只保留“有因果牵连”的（估 10~20%），单条 ≤ 60B → 约 6MB。

验收化：在 Xiaomi 2311DRK48C 上，补算 100 年世界史耗时 ≤ 30 秒；游戏运行保底 60 FPS（10.1）。

4.7 治乱与规模的关系【已定】

治乱循环在 10 万档下由 L2/L3 统计层驱动，L0/L1 只负责玩家可见范围内的细节。不允许为了“让玩家看到治乱”而把 L2/L3 降成逐个体模拟。

4.8 春夏秋冬与地理特色【已定】

· 主世界 / T1~T3 常规节点：季节由世界时间驱动，单向不可逆，影响灵气产出、资源再生、NPC 行为。
· 秘境 / 小世界 / 洞天福地：时钟域独立，季节可不按主世界走——恒春、凝滞于某一季均可。
· 地理特色：3.5“程序化 + 地标锚点”不变。
· 品阶与季节：神地可无视常规季节，灵地季节影响灵气丰枯，凡地季节影响农产。

5. 因果与恩怨

5.1 恩怨由交易不对称产生【已定】

行为 交易语义 记什么
等价交换 净收益对称 中性，关系权重略增
单向让利 对方净收益为正、我为负 记恩（欠债边）
拒绝交换 对方机会成本损失 记怨，权重按损失量
掠夺 / 赖账 强制单方得利 记死仇，且带证据

· 恩是债，仇也是债；两者都能被继承，也能被第三方继承。
· “帮了会回报、不帮会记恨”不需要单独的道德系统，是交易规则的直接产物。

5.2 记忆与衰减【已定】

记多久、会不会忘 → 衰减机制 + 摘要（见 4.4）。具体参数【待定】。

5.3 掠夺 vs 交易：善恶版图自动生成【已定】

· 抢的成本 = 受伤风险 + 报复 + 信誉崩坏 + 社会惩罚期望（见 5.7）
· 换的成本 = 让出自己一部分
· 实力差大、治安差、无第三方惩罚 → 抢划算。于是世界自然分化：

区域类型 判定（近 10 年统计） 本质
交易秩序区 交易 : 掠夺 ≥ 20 : 1，且有第三方执法 某组织已垄断暴力并收保护费
掠夺荒野区 掠夺 : 交易 ≥ 3 : 1，且无第三方执法 暴力真空

· 秩序区形成条件 = “有人能对违约者施加惩罚”：组织提供保护 → 抽税 → 税收养兵 → 更能保护 → 交易涌入 → 税更多。
· 边界移动三驱动：组织扩张 / 资源发现 / 保护者死亡。

5.4 多重归属冲突【已定：天然剧情引擎】

一个人可同时是“家族子弟 + 宗门弟子 + 国家子民”。冲突无需预先写剧本。

5.5 权力的血缘基础【已定】

顶端个体繁衍 = 培养亲信 → 血缘网络成权力骨架 → 嫡庶之争 / 分家夺权 / 亲信变对手。

5.6 存档：世代链与不可回溯【已定】

· 存档 = 种子 + 事件日志（append-only），只前进不倒退。
· 每次死亡 → 该世代档案转只读封存，新一世在同一世界状态上继续追加 → “世代链”。
· 三条工程要求：
  1. 预写日志（WAL）+ 定期检查点，只用于崩溃恢复，不向玩家提供“读回某年”的功能。
  2. 关键判定（死亡、组织灭亡、功法改良成功、品阶升降、法宝重炼、小世界开辟/坍塌）写日志即视为“史实”，不得回改。
  3. 重放必须确定性：同种子 + 同事件日志 → 世界状态哈希必须一致。

5.7 NPC 目的性与社会评价【已定】

每个 NPC 有自己的目的。玩家对 NPC 的行为在交易语义上有精确落点（5.1）：

玩家行为 交易语义 记什么
帮助 单向让利 记恩债
无视 对方机会成本损失 记怨（按损失量）
抢夺 强制单方得利 记死仇 + 证据

“怀重宝无护道者被杀人夺宝” 不需要新规则——它是 5.3 掠夺成本公式的直接结果。品阶越高、宝物越稀有，目标越显眼。

“正面评价抑制恶人动手” 在掠夺决策函数中增加一项 社会惩罚期望：目标在交易秩序区内有高信誉 → 动手后没人跟你交易、组织执法、围观者记仇。这不是道德系统，是成本核算。

“第一印象 + 后续权重”【已定·本轮扩充】：

印象 = 一次交互后评价者对被评价者形成的预期行为先验，表现为交易边权重的初始偏置。后续权重仍由 5.1 恩债/仇债累积驱动。印象只对有信息渠道的 NPC 可见，不是全局声望条。

印象的形成受三个因素影响【已定】：

因素 权重 说明
直接见闻 高 亲眼所见、亲身经历的场景，权重最大
道听途说 低 听说的、传闻的，权重远小于直接见闻
时空与人物 中 印象受“在什么时间、什么地点、通过谁”影响——同一件事，在秩序区目睹与在荒野传闻，效果不同；由高修为/高地位者转述，权重更高

重复传播会放大印象【已定】：

· 说多了，印象也会大。同一件事被多方重复传播（多人目击、多次转述、组织内部通报），印象权重累积放大。
· 但放大有上限：道听途说的重复传播，其权重总和不超过一次直接见闻（防止“谣言刷声望”）。
· 直接见闻的重复（多次亲眼看到同一行为模式）可超过单次见闻，累积为“根深蒂固的印象”。

工程含义：

· 印象不是全局标量，是每个评价者对每个被评价者的边权重偏置，且带来源标签（直接/传闻/转述）。
· 来源标签决定衰减速率：传闻衰减快，直接见闻衰减慢。
· 采样与重放仍走确定性重建（4.6 解法二），印象边作为“差异记录”的一部分被保存。

品阶与印象：神品出身者初始关注度高，但关注 ≠ 好感——可能引来攀附，也可能引来觊觎。印象的最终方向仍由实际行为决定。

6. 生死与轮回

6.1 死亡判定【待定】

自然寿元、战死、被伐（草木）、被杀（兽）、走火入魔等，具体权重待定。寿元按体系分表（2.4），人族、草木、兽类各有寿元曲线。

6.2 生平评分：综合 + 主观【已定】

“对这些都要综合评分，主观。”

```
① 事实层：一生做过的事（客观事件记录）
② 评价层：谁还记得你、怎么评价你（多主体主观评价聚合）
③ 裁决层：加权汇总 + 扰动 → 判词
```

· 只有记得你的人的评价才计入 → 被遗忘的人无分。
· 权重 = 评价者修为 × 地位 × 与你的亲密度 × 记忆新鲜度（衰减）× 人数 × 印象来源权重（5.7）。
· 同一人在不同地区评价可以相反 → 由全局加权裁决。
· 呈现方式主观、不可算：用一段判词给出结果，不显示分数明细（防止刷投胎）。
· 综合维度：修为、善行、恶行、影响过多少人、留下什么、欠债与还债。

6.3 投胎规则【已定】

· 评分不直接决定身份，而是转成六道/身份权重 + 品阶权重 + 体系权重 + 出身地、家庭、时代随机。
· 任何身份都有机会获得修炼机会（草木可成灵、兽可成妖、乞儿可入道）。
· 世界时钟不重置：投胎后进入仍在演化的同一世界。
· 每一世开局体验都在洪荒早期（2.1）——投胎后的出身节点处于该世界演化序列中的洪荒早期形态，不是世界时钟倒流。
· 品阶采样的因果偏置：作恶多端 → 向凡品/非人凡品偏移；行善 → 向灵品/人偏移。但“凡品不是绝路，神品不是保险”。
· 投胎不是“分解重炼”：个体的品阶升降记录不因投胎而重置（那是前世的事），但新一世的身体/根骨品阶按因果账本重新采样。

6.4 跨世继承【已定/待定】

保留：灵魂 ID、因果账本（恩债仇债）、部分记忆（比例待定，见 6.7）、道统影响、品阶的因果偏置（不是品阶本身）、印象的来源标签（不是印象本身）。
不保留：修为、地位、身体、具体品阶（投胎时按账本重新采样）、具体体系（投胎可换体系）。

6.5 草木世【已定】

· 不能移动，只能被动吸收资源（灵气/水/光）。
· 出生地决定命运（灵脉旁=生机，荒漠=慢性死亡）。
· 玩法 = 影响半径：根系延伸、种子扩散、树冠庇荫；结果实、聚灵气、庇护小兽。
· 修士、兽群、樵夫会来取用/砍伐/供奉 → 全记在你账上。
· 品阶：凡草 / 灵草 / 神药。古树可化灵、可修成树妖——这是凡品→灵品的升阶路径，一生只能升一次（接入 2.15）。
· 体系独立：草木有独立境界链与寿元表（2.4），不套用人族境界。

6.6 兽类世（以狗为例）【已定】

· 依附型生存：有主人，靠主人获得食物、庇护、地位。
· 核心属性：忠诚度；行为：护主、寻物、示警、咬人。
· 主人的仇即你的仇，主人的势即你的势——跟对人则安，跟错人则随葬。
· 同样可修炼（妖犬/灵兽），路径依附主人道统。
· 品阶：凡兽 / 灵兽 / 神兽。凡兽可因主人道统或机缘升为灵兽，一生只能升一次（接入 2.15）。
· 体系独立：兽类有独立境界链与寿元表（2.4），不套用人族境界。

6.7 因果账本与“相欠相见”【已定】

区分两件事：

· 因果账本（恩债/仇债/业力）：跨世保留的结构性数据，决定投胎权重、出身环境偏置、品阶采样偏置、体系采样偏置、以及“谁会出现在你生命里”的生成采样偏置。
· 记忆：建议中间态——保留“亏欠感/亲近感/莫名敌意”的模糊情绪先验，不保留具体事件记忆。玩家遇到一个 NPC，不知道为什么就是不信任他，或莫名想帮他；账本在后台驱动，但不给可读数值。

“相遇 NPC 与因果相关”的工程含义：不把账本里的 NPC 硬塞到玩家面前，而是在 NPC 进入视野的采样权重上加因果偏置。仍走确定性重建（4.6 解法二），不破坏“同种子同人”。

“没有相欠，何来相见” 作为因果系统的设计原则，不单独设“缘分”属性——缘分就是账本在采样权重上的投影。

业力与投胎的具体落点：作恶多端 → 六道权重向非人/低出身偏移，品阶向凡品偏移；行善 → 向人/较好出身偏移，品阶向灵品偏移。债务体现为富贵层次、出生环境、以及相遇 NPC 的采样偏置。全部由账本数据驱动，不写死剧本。

7. 玩法循环

7.1 单局（一世）【已定】

出身 → 求存（交易/依附/掠夺）→ 入组织 → 修炼 → 洞府/载具/功法/法宝 → 恩怨 → 死。

7.2 长线（跨世）【已定】

世界持续演化，每一世在同一个世界里留下痕迹（组织、功法谱系、恩怨、建筑、法宝、小世界），下一世进入已被自己改变过的世界。

7.3 玩家自由度边界【待定】

7.4 开发节奏：长线，但必须阶段可交付【已定】

“长线联机世界，慢慢开发，不着急”。

· 允许以年计的长周期，但不接受“做到一半推倒重来”。
· 每个阶段必须有可独立交付、可玩、可验证的产物：

阶段 可交付物 为什么它不会白做
P0 无头世界模拟器：种子 → 100 年世界史日志 数据层与架构无关引擎，永久复用
P1 参数化角色查看器 + 2.5D 相机/光影验证场景（保底 60 帧验证） 与写实材质库绑定，是最终管线的核心；同时验证移动端帧率
P2 时间流速 + 离线补算 + 世代存档 + 小世界开辟/流速自定义 决定“长线”能否成立的基建
P3 轮回与因果账本（含品阶/体系采样、印象来源权重） 玩法闭环成立
P4 联机（首版之后，权威服务器 + 事件同步） 在最贵的基建之前先验证玩法

· 顺序铁律：P0 未通过验收，不进入 P1；P3 未跑通轮回，不上线服务器。

8. 联机【已定：首版单机，保留联机接口】

“那就首版做单机吧，保留联机接口”。

首版不联网，但架构上必须现在就为联机留好，改动只在接线，不在重构。五条铁律：

# 铁律 为什么现在就要
1 世界模拟必须 headless 可跑 同一套代码本地跑 = 将来服务器跑
2 确定性：同种子 + 同事件 → 世界状态哈希一致 否则联机无法校验，也无法重放
3 一切状态变更走事件总线，事件结构可直接序列化 单机的“事件”就是将来的“网络消息”
4 存档格式面向服务端：本地存档 = 服务端世界的一个分片 将来上传/下发无需改格式
5 时间戳统一用 世界时间 + 进入序号，禁用设备本地时间 换设备/联机后必然需要

8.1 将来联机的形态（保留决策，不在首版实现）

```
① 世界层（权威）：服务器跑确定性模拟，客户端只订阅自己所在节点的状态
② 同场景层：真实时同步，限局部（同秘境/同战场/同洞府）
③ 异步层：书信、交易、留言、遗迹、跨世痕迹（成本最低，价值最高）
```

· 常驻服务器是联机阶段的月成本（$10~25/月量级），首版单机为 0。
· 设定红利保留：你上一世建的洞府、炼的法宝、开辟的小世界，将来别的玩家的新角色可能真的挖到。
· UE5 下的含义：UE5 的联机框架（Replication）只用于 ② 同场景层；① 世界层仍以 SimCore 确定性模拟为准。

9. 美术与表现

9.0 最高审美原则【已定】

一切为了好看。当视觉表现与工程便利、性能余量、CI 速度、资产成本冲突时，优先保视觉表现；工程手段围绕好看服务，而不是让美术迁就架构。

但“好看”必须可验收，否则无法冻结。5 条视觉标准（见第 11 章第 26~30 条）：

26. 统一光影：同场景所有角色/衣饰/建筑/特效的受光方向、色温、阴影软硬一致，不出现“贴纸感”。
27. 材质质感：布料、金属、皮肤、玉石、灵光各有可辨识的材质响应，不是纯色平涂。
28. 角色辨识度：两个不同出身/组织/品阶/体系的角色，不看 UI 能通过轮廓、配色、纹样、灵光区分。
29. 场景层次：远观与近看两档下均有前景/中景/背景层次，不塌成平面。
30. 特效不廉价：功法异象有起手/命中/收招节奏，同源功法可辨谱系。

9.1 风格：2.5D 写实【已定】

```
场景 = 3D 地形/建筑/植被（低模 + 烘焙光照 + LOD）
角色 = 3D 低模 + Morph Target / 骨骼缩放 / 动态材质参数化
相机 = 正交等距（默认）或低 FOV 透视
质感 = 手工绘制材质 + 统一光影 + 色调映射
```

· 为什么不是 2D 纸娃娃：UE5 的强项是光影与材质；2D 纸娃娃在 UE5 移动端既不是引擎一等公民，又放弃了 UE5 最擅长的东西。选 3D 低模 + 2.5D 相机，是“一切为了好看”的直接推论。
· 2.5D 写实的成败：烘焙质量与统一光影。Lumen/Nanite 在移动端不可依赖（10.2.2）。
· 品阶的视觉层级：凡品无灵光，灵品微光，神品异象——这是“好看”与“可读性”的交汇点。法宝同理：凡品无光效，灵品自发光，神品异象+器灵虚影。
· 体系的视觉层级：人族偏道袍/法冠/灵光；草木系偏植物形态/根系/花果；兽类系偏兽形/毛皮/血脉纹路。

9.2 立绘【已定】

由同一组角色参数 + 同一套 3D 资产实时渲染，禁逐次 AI 重生成。

9.3 特效自定义范围【已定】

见 3.11（异象词库 + 参数化 + 性能预算）。2.5D 下走 Niagara + 材质叠加。

抗锯齿 按设备档位选择（Mobile 默认方案）

这是“好看”的预算边界：好看靠烘焙质量 + 材质 + 配色 + 构图 + 特效节奏。保底 60 帧的代价：如果 60 帧与视觉五条冲突，优先保 60 帧（10.1 已定），然后在不破坏统一光影的前提下优化材质与构图，而不是牺牲帧率换光效。

10.5 代码分层：SimCore（纯 .NET）+ Presentation（UE5 C++）【已定】

```
SimCore = 纯 .NET 类库（不引用 UnityEngine，不引用 Unreal）
  世界种子、时间轴、交易撮合、组织演化、事件日志、判词、因果账本、品阶采样、
  升阶/降阶/重炼判定、三套修炼体系推进、三套寿元表、小世界开辟预算与流速成本、
  印象来源权重计算
  可在 dotnet 控制台独立跑 → P0 无头模拟器

Presentation = UE5 工程（C++ 为主，Blueprint 用于表现层）
  只读 SimCore 的状态与事件，负责渲染/输入/音频
  通过 P/Invoke / gRPC / 本地 socket / 文件快照消费 SimCore 输出
```

· 好处一：P0 无头世界模拟器不用进 UE5，纯控制台跑 100 年世界史，几秒钟出日志。
· 好处二：将来上服务器，SimCore 直接部署，不用重写。
· 铁律：UE5 侧不得写任何影响世界状态的逻辑；所有状态变更只能发生在 SimCore 内并由事件总线广播。
· 集成方式待 P0 后实测：P/Invoke / gRPC / 本地 socket / 文件快照。P0 先定接口契约，P1 再选实现方式。

10.6 全 CI 开发与发布流水线（UE5 版）【已定】

UE5 通过 Unreal Automation Tool（UAT）/ RunUAT BuildCookRun 命令行可无界面打包 Android，并可集成到 GitHub Actions。

前提：UE5 的 Editor Scripting 可以无界面运行——场景、Actor、Data Asset、Widget、材质、导入设置都能用 Editor Utility / C++ / Python 创建。代价是把原本手工点击的操作全部写成 Editor 脚本。

```
① 资产生成
   UnrealEditor-Cmd.exe Project.uproject -run=pythonscript 或 Editor Utility/C++ 工具

② 世界验证
   dotnet run --project SimCore.Cli

③ 构建 APK
   RunUAT BuildCookRun -project=... -platform=Android -cook -build -stage -package -archive

④ 签名与校验
   体积 / sha256 / 版本号与 SimCore 版本一致性

⑤ 发布
   GitHub Actions → 上传 artifact + 滚动更新 Release（APK + sha256）

⑥ 手机验证
   下载 APK 安装 → 回填验收结果（含 60 FPS 实测）
```

技术约定：

项 约定 理由
Shader 手写 .usf / 材质函数，控制版本可 diff 图节点是二进制资产，CI 无法 diff
场景 只保留一个极简 Bootstrap 场景，其余内容运行时由 SimCore 数据程序化生成 减少对“人工摆场景”的依赖
资产 GUID 统一由 Editor 脚本生成/导入，避免手工重导入导致引用断裂 GUID 变了引用就断，是 CI-only UE5 的头号坑
美术资源 外部生成（含 AI 生图）→ 入库 → 由 Editor 脚本统一设导入参数 保证压缩 / LOD / 流送一致
版本号 单一来源（SimCore 的 version 常量）→ 构建时写入 APK 避免版本对不上
密钥 GitHub Token 只放 Secrets 沿用上次 PAT 泄露的教训

UE5 CI 与 Unity CI 的差异（必须接受）：

· UE5 没有 GameCI 那种开箱即用的 Docker 镜像。GitHub Actions 上的 UE5 构建通常需要自备 UE 安装或使用第三方 Action。
· Cook 时间显著长于 Unity。“commit 到可装 APK”的周期会从 5~15 分钟量级拉长到30 分钟~数小时。
· Editor 脚本本身就是代码：资产程序化生成在 UE5 中通过 Editor Utility / C++ / Python 完成，首版学习成本高于 Unity 的 -executeMethod。

收益：从“commit”到“手机可装的 Release”全程无人值守。

11. 验收标准（42 条，可测）

世界演化

1. 从零个体跑 200 年，自发出现 ≥3 种不同类型的组织。
2. 至少一次分裂、一次合并。
3. 至少一个组织灭亡，且原因可追溯到具体事件链。
4. 玩家入场时，组织不是预设的，而是这 200 年长出来的。
5. 自发长出交易网络，呈现核心-边缘结构（前 5% 节点承载 ≥50% 交易量）。
6. 同时存在交易秩序区与掠夺荒野区（各 ≥15% 节点），且每年 ≥3% 节点易主。
7. 自发出现一般等价物（非开局预设）。
8. 从零跑 100 年，自发出现家庭结构；人口曲线在饥荒/战乱年份出现可解释下跌。
9. 从零跑 500 年，至少出现一次“统一 → 崩解 → 再统一”完整循环。

功法与视觉

10. 两个同源功法在视觉上能被人一眼认出同源。
11. 缩放档切换时，人物尺寸不跳变、半透明排序不错乱。
12. 500 年后不存在压倒性的单一最优功法。
13. 同一组捏脸参数换装后，立绘不换人。

规模与确定性

14. 10 万在册档位下，补算 100 年世界史在 Xiaomi 2311DRK48C 上 ≤ 30 秒。
15. 崩溃恢复后，世界状态哈希与崩溃前完全一致。
16. 存档中不存在任何“回退到过去某年”的入口。
17. 任意体型 × 任意版型生成后，衣片与身体骨骼对齐、蒙皮无严重穿插、半透明排序正确。
18. 世界模拟模块可在无渲染/无 UI 环境下独立运行（headless），且与联机接口共用同一份代码。
19. 从 commit 到手机可安装 Release 全程无人工干预。
20. 每次发布的 APK 内版本号、世界史哈希与 SimCore 一致，且能通过 CI 校验。

地图/资源/因果/季节

21. T3 地球当量节点上，L0 层活跃个体 ≤800 时，单帧推进 ≤8ms；资源消耗事件逐条入日志，无回退入口。
22. 同一资源在 L0 被消耗后，重放世界状态哈希与崩溃前一致，且不存在“资源恢复”API。
23. NPC 掠夺决策中“社会惩罚期望”可追溯——一次“因正面评价而放弃抢夺”的决策，能定位到具体评价主体与权重来源。
24. 投胎后第一批 NPC 中，至少一个的生成采样权重受上一世因果账本显著影响，且可通过确定性重建复现。
25. 主世界季节单向不可逆；秘境节点可独立于主世界季节，两者切换时世界状态哈希不冲突。

视觉五条

26. 统一光影：同场景所有角色/衣饰/建筑/特效的受光方向、色温、阴影软硬一致，不出现“贴纸感”。
27. 材质质感：布料、金属、皮肤、玉石、灵光各有可辨识的材质响应，不是纯色平涂。
28. 角色辨识度：两个不同出身/组织/品阶/体系的角色，不看 UI 能通过轮廓、配色、纹样、灵光区分；法宝品阶同样可通过光效/异象辨识。
29. 场景层次：远观与近看两档下均有前景/中景/背景层次，不塌成平面。
30. 特效不廉价：功法异象有起手/命中/收招节奏，同源功法可辨谱系。

引擎与流水线

31. UE5 移动端构建中 Lumen 与 Nanite 处于关闭状态，且画面在烘焙光照下达到第 26 条“统一光影”标准。
32. 从 commit 到手机可安装 Release 的 CI 流水线在 UE5 下无人值守跑通，APK 版本号与 SimCore 版本一致，构建日志可追溯到 commit SHA。

品阶系统

33. 同一世界内，凡人 / 普通修士 / 隐世大能 / 草木 / 野兽 / 资源 / 功法 / 法宝均带凡品/灵品/神品标签，且品阶与境界是两个独立字段——存在“凡品出身的高境界者”与“神品出身的低境界者”。
34. 投胎品阶分布受因果账本影响可追溯：作恶多端者的下一世品阶向凡品偏移、行善者向灵品偏移，且该偏移可通过确定性重建复现；同时凡品出身仍存在修炼到高境界的路径（不构成绝路）。
35. 升阶一生一次：任一物品/个体升阶后，不能再自行升到更高品阶；升阶后降阶为单向不可逆，降后不能回升；分解重炼是唯一重置手段，重炼后品阶状态归零、重新获得一次升阶机会，且原附加属性/因果/记忆按重炼规则处理（丢失或改变）。
36. 功法品阶受创造者实力上限约束：同一门功法理念，由不同实力/品阶的创造者创造，品阶不同；创造者无法造出高于自身实力映射上限的功法；强行创造高品阶功法时反噬概率显著上升。
37. 法宝品阶受炼制者实力与材料品阶共同约束：取两者映射上限的低者；凡品材料炼不出神品法宝；法宝升阶/降阶/重炼规则与第 35 条一致；神品法宝自带因果（前任仇家、器灵执念）可随法宝过户。

修炼体系/开局/小世界/印象/帧率（本轮新增）

38. 人与动植物各有独立修炼体系、境界链、寿元表：存在“同境界名在不同体系内不对应”“同寿元数字在不同体系内不等价”的可验证差异；三套体系的数据表可分别外置与校验。
39. 每一世开局体验在洪荒早期：无论第几世，玩家出身节点在进入时呈现低组织度、低灵气开发、资源原始的洪荒早期形态；世界时钟不重置，仅开局节点形态锚定。
40. 小世界开辟与流速自定义必须有代价：高境界者可开辟 T1~T3 小世界、开辟空间节点、定义时间流速；开辟面积与流速倍率均触发超线性维护成本与稳定性惩罚；低成本高倍率不可行；小世界坍塌不可恢复，但可散落为遗迹。
41. 第一印象受来源影响：直接见闻的权重显著高于道听途说；时空与人物（时间、地点、转述者修为/地位）影响印象权重；重复传播会放大印象，但道听途说的重复放大有上限，不超过一次直接见闻。
42. 保底 60 FPS：在 Xiaomi 2311DRK48C 上，P1 视觉验证场景与最终构建均须稳定 60 FPS；低于 60 FPS 即视为未达标，须通过降密度/降光影/降粒子保 60，而不是接受 30。
