# 《一世》界面设计规范 v1.0（Unity 重做版）

> 结论先说：上一版丑，不是因为颜色不好看，而是因为**没有版式**。顶栏、状态卡、行囊条、12 键命令区、3×3 行动面板、立绘面板、方向键、事件流各自用自己的坐标画，互相压、互相抢。这一版只保留一套版式、一套令牌、一条层级。

## 一、设计目标

| 目标 | 可验收标准 |
|---|---|
| 一眼看懂 | 进游戏 3 秒内能说出：我是谁、什么境界、还剩多少寿元、能做什么 |
| 一屏一事 | 主界面只有一条「世界钟 → 人物 → 地图 → 事件 → 指令」的阅读动线 |
| 触控可达 | 所有可点区域 ≥ 88×88 px（1080 参考宽度），间距 ≥ 12 px |
| 不再叠层 | 面板以「底部弹层」出现，一次只开一个；地图操作区永不被浮层遮住 |
| 字压得住 | 地图再花，文字底下必有压角或面板，正文对比度 ≥ 4.5:1 |

## 二、设计令牌（`Assets/Scripts/UI/UiKit.cs → Tok`）

### 2.1 色板

| 令牌 | 色值 | 用途 |
|---|---|---|
| `Ink` | `#0B1210` | 夜色底、压角、判词页 |
| `Ink2` | `#12201A` | 渐变上端 |
| `Panel` | `#0E1714 @94%` | 面板底 |
| `PanelHi` | `#16241E @96%` | 按钮底 |
| `Paper` | `#F2EADB` | 主文字（纸白，不纯白，久看不刺眼） |
| `Sub` | `#B9C4B6 @82%` | 次要信息 |
| `Faint` | `#7F8F83 @55%` | 说明、水印 |
| `Gold` | `#D9B463` | 强调、品阶、金额 |
| `Cinnabar` | `#C05B45` | 危险、死亡、抽成过重 |
| `Jade` | `#8FD3B4` | 生机、寿元、玩家、灵品 |

五行对应：墨为底、纸为字、金为骨、朱砂为警、青玉为生。**除这五个色相外不引入新色**，保证画面统一。

### 2.2 字号（1080×1920 参考）

`Title 44 / H1 34 / Body 28 / Small 24 / Caption 21`。正文最小 21，不再出现 12–14px 的小字（上一版最丑的一处）。

### 2.3 间距与圆角

- 外边距 30；面板内边距 24；控件间距 12。
- 面板圆角 22，卡片 16，按钮 14，胶囊 999。
- 发丝线：2 px，金色 22% 透明。

```

│ 顶栏  Y12·3月 春    [洪荒·早期]  ⏸ 1×2×4× │ 高 98
├──────────────────────────────────────────┤
│ 人物卡  命 慕容珩                       │ 高 194（宽 720，左对齐，不铺满）
│         人·金丹(4境)·第3世   [灵品]      │
│         灵石 12 · 名望 8 · 恩 4 怨 1     │
│         寿元 ▓▓▓▓▓░░░  修为 ▓▓░░░       │
│         最近事件……                       │
├──────────────────────────────────────────┤
│                                          │
│              地图（全屏铺底）             │
│        点人=选中   点地=走过去            │
│                                          │
│   [选中人物条：姓名/境界/品阶/印象 帮 拒 夺] │ 高 112（仅选中时）
├──────────────────────────────────────────┤
│ 事  最近一条事件（单行，超长省略）          │ 高 58
├──────────────────────────────────────────┤
│ 修行  行善  夺灵  洞府  入宗              │ 高 72
│ 开辟  渡门  游历  种灵  采脉              │ 高 62
│ 升品  炼宝  改流速 待月  卷宗             │ 高 46
└──────────────────────────────────────────┘ 16
```

- 人物卡只占左侧 720 px，右侧留白给地图（避免"整块黑板压住世界"）。
- 指令坞 5 列 × 3 行 = 13 个动词 + 卷宗；一行比一列好按，拇指自然区。
- 事件条永远在指令坞上方，**不与面板重叠**（上一版事件流被面板盖住）。

## 四、弹层（卷宗）

点「卷宗」从底部升起 1240 px 的面板：遮罩 + 把手 + 标题 + 五个页签（身世/洞天/宗门/世系/设定）+ 内容区。

- 一次只开一个；点遮罩或 × 关闭。
- 内容用「左标签 240 / 右值 760」两列行高 54，不做滚动列表，超过 9 行分页。
- 危险动作（分解重炼）用朱砂字，按钮右置，不放在主指令坞里防误触。

## 五、判词页

死亡即全屏：墨底、纸白大字、朱砂「判」印、四行生平、来世去向与因果解释，底部一枚金色「再入轮回」。**不显示分数**，只出断语（需求 §6.2）。

## 六、动效与性能

- 只做三类动效：面板 160ms 淡入、选中环呼吸、行走 0.16s/格插值。不做粒子、不做模糊。
- UI 每 0.25s 同步一次文本，不在 `Update` 里重建控件；面板内容仅在打开或操作后重建。
- 地图三批绘制：地形、地物、人物各一张网格（3 个 draw call）。无实时阴影、无实时 GI。
- 目标 60 FPS：`Application.targetFrameRate = 60`，`vSyncCount = 0`，URP 资产在构建时生成，失败自动退回内置管线。

## 七、与旧版的差异（为什么这次不丑）

| 旧版 | 新版 |
|---|---|
| 8 套面板各自定位 | 1 套版式 + 1 个弹层容器 |
| 颜色 20+ 种、随机高光 | 5 色令牌，禁用新色相 |
| 正文 12–16 px | 正文 21–28 px |
| 事件流被面板遮挡 | 事件条固定在指令坞上方，弹层不覆盖 |
| 点画面推进年份 | 点人选中、点地寻路；时间常开 |
| 立绘面板 + 3×3 面板 + dpad 三套输入 | 一套指令坞 + 地图直达 |

## 八、字体与资源

- 中文：`Assets/Resources/Fonts/NotoSansSC-Regular.ttf`（实为 Droid Sans Fallback，Apache-2.0，含 CJK，已随仓库分发）。
- 圆角/渐变均为运行时生成纹理与九宫 Sprite，工程内零 UI 美术资源。
- 图标用「单字印」（修/善/夺/府/宗…），不引入图标字体与 emoji。
